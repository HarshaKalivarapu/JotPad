contentEditable — hands-on demo

This file is just for learning. It is not used by JotPad. Delete the whole demo/ folder when you're done.

To run: just double-click this file, or drag it into a browser tab. No server, no build step needed.

Lesson: a textarea is a black box with one string inside. A contentEditable element holds a tree of nodes — text nodes, element nodes (like <strong>), maybe <br> tags. That tree is what makes inline styling possible. It is also what makes everything else harder.

Lesson: the cursor is not a number like it is in a textarea. It is a pair: which DOM node it is in, and the offset within that node. If that node gets destroyed, the cursor has nothing to anchor to.
